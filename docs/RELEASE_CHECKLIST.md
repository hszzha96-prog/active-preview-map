# 发布检查清单

## 代码

- [ ] 更新 `package.json` 版本号
- [ ] 更新 `CHANGELOG.md`
- [ ] 运行 `pnpm lint`
- [ ] 运行 `pnpm build`
- [ ] 检查桌面和移动布局

## 功能

- [ ] 上传 PDF 并生成节点
- [ ] 上传 PPTX 并生成节点
- [ ] 节点可编辑、筛选与导出
- [ ] 原课件跳转页码正确
- [ ] 延伸学习检索词与当前页一致
- [ ] 外部资源在新标签页打开

## 隐私与安全

- [ ] ZIP 和 Git 提交不包含 `.env`
- [ ] 不包含真实 API 密钥
- [ ] 不包含用户课件或测试文件
- [ ] 不包含 `.openai/hosting.json` 中的项目专属 ID
- [ ] 不包含 `node_modules`、构建缓存和本地运行状态

## GitHub Release

- [ ] 创建 `vX.Y.Z` 标签
- [ ] 填写 Release title 和 Release notes
- [ ] 上传源码 ZIP
- [ ] 确认 README 在线演示链接有效
